# Grundlagen der Analysis

Edmund Landau, *Grundlagen der Analysis (Das Rechnen mit ganzen, rationalen,
irrationalen, komplexen Zahlen)*, Akademische Verlagsgesellschaft M.B.H.,
Leipzig 1930.

OCR されたスキャン PDF からテキストを抽出・修正し、markdown 化したものです。
数式は LaTeX(KaTeX)でレンダリングされます。
