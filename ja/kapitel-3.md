# 第3章 切断

## § 1. 定義

**定義 28:** 有理数の集合は、次を満たすとき切断と呼ばれる。

1) それはある有理数を含むが、すべての有理数を含むのではない。

2) 集合のどの有理数も、集合に属さないどの有理数よりも小さい。

3) その中に最大の有理数(すなわち、それと異なる他のあらゆる数よりも大きい数)が現れない。

この集合を下組とも呼び、そこに含まれない有理数の集合を上組と呼び、それに応じて下数および上数という言い方をする。

小文字のギリシャ文字は、特に断らない限り、常に切断を表す。

**定義 29:**

```math
\xi = \eta
```

($=$ 読み方:等しい)とは、$\xi$ における各下数が $\eta$ における下数であり、$\eta$ における各下数が $\xi$ における下数であることをいう。

言い換えれば、両集合が一致するときである。

そうでない場合は

```math
\xi \neq \eta
```

($\neq$ 読み方:等しくない)。

次の三つの定理は自明である。

**定理 116:** $\xi = \xi$.

**定理 117:**

```math
\xi = \eta
```

から

```math
\eta = \xi.
```

が従う。

**定理 118:**

```math
\xi = \eta, \quad \eta = \zeta
```

から

```math
\xi = \zeta.
```

が従う。

**定理 119:** $X$ が $\xi$ における上数であり、

```math
X_1 > X,
```

ならば、$X_1$ は $\xi$ における上数である。

**証明:** 定義 28 の 2) から従う。

**定理 120:** $X$ が $\xi$ における下数であり、

```math
X_1 < X,
```

ならば、$X_1$ は $\xi$ における下数である。

**証明:** 定義 28 の 2) から従う。

もちろん逆に、定理 120 の要請は定義 28 の 2) と同一である。したがって、有理数の何らかの集合が切断であることを示すには、常に次のことを証明すれば十分である。

1) それは空でなく、かつそこに属さない有理数が存在する。

2) その各数とともに、それより小さい各数もそこに属する。

3) その各数に対して、その中により大きい数が存在する。

## § 2. 順序

**定義 30:** $\xi$ と $\eta$ が切断であるとき、

```math
\xi > \eta
```

($>$ 読み方:より大きい)とは、$\eta$ における上数であるような $\xi$ における下数が存在することをいう。

**定義 31:** $\xi$ と $\eta$ が切断であるとき、

```math
\xi < \eta
```

($<$ 読み方:より小さい)とは、$\eta$ における下数であるような $\xi$ における上数が存在することをいう。

**定理 121:**

```math
\xi > \eta
```

から

```math
\eta < \xi.
```

が従う。

**証明:** まさに、$\xi$ における下数であるような $\eta$ における上数が存在するからである。

**定理 122:**

```math
\xi < \eta
```

から

```math
\eta > \xi.
```

が従う。

**証明:** まさに、$\xi$ における上数であるような $\eta$ における下数が存在するからである。

**定理 123:** $\xi$、$\eta$ が任意であるとき、

```math
\xi = \eta, \quad \xi > \eta, \quad \xi < \eta
```

のうちちょうど一つの場合が成り立つ。

**証明:** 1)

```math
\xi = \eta, \quad \xi > \eta
```

は定義 29 と定義 30 により両立しない。

```math
\xi = \eta, \quad \xi < \eta
```

は定義 29 と定義 31 により両立しない。

```math
\xi > \eta, \quad \xi < \eta
```

からは、$\eta$ における上数であるような $\xi$ における下数 $X$ が存在し、かつ $\eta$ における下数であるような $\xi$ における上数 $Y$ が存在することが従うであろう。定義 28 の 2) により、したがって同時に

```math
X < Y, \quad X > Y.
```

となるであろう。ゆえに、三つの場合のうち高々一つが成り立つ。

2)

```math
\xi \neq \eta,
```

ならば、下組は一致しない。したがって、$\xi$ におけるある下数が $\eta$ における上数であり、そのとき

```math
\xi > \eta,
```

であるか、または $\eta$ におけるある下数が $\xi$ における上数であり、そのとき

```math
\xi < \eta.
```

である。

**定義 32:**

```math
\xi \geqq \eta
```

は

```math
\xi > \eta \text{ または } \xi = \eta.
```

を意味する。

($\geqq$ 読み方:より大きいか等しい。)

**定義 33:**

```math
\xi \leqq \eta
```

は

```math
\xi < \eta \text{ または } \xi = \eta.
```

を意味する。

($\leqq$ 読み方:より小さいか等しい。)

**定理 124:**

```math
\xi \geqq \eta
```

から

```math
\eta \leqq \xi.
```

が従う。

**証明:** 定理 121。

**定理 125:**

```math
\xi \leqq \eta
```

から

```math
\eta \geqq \xi.
```

が従う。

**証明:** 定理 122。

**定理 126**(順序の推移律):

```math
\xi < \eta, \quad \eta < \zeta
```

から

```math
\xi < \zeta.
```

が従う。

**証明:** $\eta$ における下数であるような $\xi$ における上数 $X$ が存在し、また $\zeta$ における下数であるような $\eta$ における上数 $Y$ が存在する。$\eta$ の切断の性質 2) により

```math
X < Y,
```

であり、したがって $Y$ は $\xi$ における上数である。ゆえに

```math
\xi < \zeta.
```

である。

**定理 127:**

```math
\xi \leqq \eta, \quad \eta < \zeta \text{ または } \xi < \eta, \quad \eta \leqq \zeta,
```

から

```math
\xi < \zeta.
```

が従う。

**証明:** 仮定に等号が含まれる場合は明らかであり、そうでない場合は定理 126 によって片付く。

**定理 128:**

```math
\xi \leqq \eta, \quad \eta \leqq \zeta
```

から

```math
\xi \leqq \zeta.
```

が従う。

**証明:** 仮定に二つの等号が含まれる場合は明らかであり、そうでない場合は定理 127 によって片付く。

## § 3. 加法

**定理 129:** I) $\xi$ と $\eta$ を切断とする。このとき、$X$ が $\xi$ における下数、$Y$ が $\eta$ における下数であるような形 $X + Y$ に表される有理数の集合は、切断である。

II) この集合のどの数も、$\xi$ における上数と $\eta$ における上数の和として表すことはできない。

**証明:** 1) $\xi$ における任意の下数 $X$ と $\eta$ における任意の下数 $Y$ から出発すれば、$X + Y$ は集合に属する。

$\xi$ における任意の上数 $X_1$ と $\eta$ における任意の上数 $Y_1$ から出発すれば、$\xi$ における、また $\eta$ におけるすべての下数 $X$ および $Y$ に対して

```math
X < X_1, \quad Y < Y_1,
```

したがって

```math
X + Y < X_1 + Y_1,
```

```math
X_1 + Y_1 \neq X + Y;
```

であり、$X_1 + Y_1$ はしたがって集合に属さない。そして II) はこれで同時に証明されている。

2) 集合のある数より小さい各数も集合に属することを示さなければならない。そこで $X$ を $\xi$ における下数、$Y$ を $\eta$ における下数とし、

```math
Z < X + Y.
```

とする。このとき

```math
(X + Y) \cdot \frac{Z}{X + Y} = Z < (X + Y) \cdot 1,
```

であるから、定理 106 により

```math
\frac{Z}{X + Y} < 1,
```

であり、したがって定理 105 により

```math
X \cdot \frac{Z}{X + Y} < X
```

かつ

```math
Y \cdot \frac{Z}{X + Y} < Y.
```

である。

$\xi$ における、また $\eta$ における第二の切断の性質により、$X \cdot \frac{Z}{X + Y}$ および $Y \cdot \frac{Z}{X + Y}$ はそれぞれ $\xi$ における、また $\eta$ における下数である。

これら二つの有理数の和は、

```math
X \cdot \frac{Z}{X + Y} + Y \cdot \frac{Z}{X + Y} = (X + Y) \cdot \frac{Z}{X + Y} = Z.
```

により、与えられた $Z$ である。

3) 集合のある数が与えられたとすると、それは $X$ が $\xi$ における下数、$Y$ が $\eta$ における下数であるような形 $X + Y$ を持つ。第三の切断の性質により、$\xi$ における下数

```math
X_1 > X
```

を選べば、

```math
X_1 + Y > X + Y,
```

であるから、集合の中に $> X + Y$ なる数が存在する。

**定義 34:** 定理 129 で構成された切断を $\xi + \eta$ と呼ぶ($+$ 読み方:プラス)。これはまた $\xi$ と $\eta$ の和、あるいは $\xi$ への $\eta$ の加法によって生じる切断とも呼ばれる。

**定理 130**(加法の交換法則):

```math
\xi + \eta = \eta + \xi.
```

**証明:** 各 $X + Y$ は $Y + X$ でもあり、逆もまた同様である。

**定理 131**(加法の結合法則):

```math
(\xi + \eta) + \zeta = \xi + (\eta + \zeta).
```

**証明:** 各 $(X + Y) + Z$ は $X + (Y + Z)$ でもあり、逆もまた同様である。

**定理 132:** どの切断においても、$A$ が与えられたとき、

```math
U - X = A.
```

を満たす下数 $X$ と上数 $U$ が存在する。

**証明:** $X_1$ を任意の下数とする。$n$ が整数であるようなすべての有理数

```math
X_1 + nA,
```

を考える。これらがすべて下数であるということはない。なぜなら、$Y$ を任意の上数とすれば

```math
Y > X_1,
```

であり、定理 115 により適当な $n$ に対して

```math
nA > Y - X_1,
```

```math
X_1 + nA > (Y - X_1) + X_1 = Y,
```

であり、したがって $X_1 + nA$ は上数だからである。

$X_1 + nA$ が上数となるような $n$ の集合には、定理 27 により最小の整数が存在する。それを $u$ と呼ぶ。

```math
u = 1,
```

ならば

```math
X = X_1, \quad U = X_1 + A;
```

とおき、

```math
u > 1,
```

ならば

```math
X = X_1 + (u - 1) A, \quad U = X_1 + uA = X + A.
```

とおく。

いずれの場合も $X$ は下数、$U$ は上数であり、

```math
U - X = A.
```

である。

**定理 133:** $\xi + \eta > \xi$.

**証明:** $Y$ を $\eta$ における下数とする。定理 132 により、$\xi$ における下数 $X$ と $\xi$ における上数 $U$ で

```math
U - X = Y;
```

を満たすものを選ぶ。すると

```math
U = X + Y
```

は $\xi$ における上数であり、$\xi + \eta$ における下数である。ゆえに

```math
\xi + \eta > \xi.
```

である。

**定理 134:**

```math
\xi > \eta
```

から

```math
\xi + \zeta > \eta + \zeta.
```

が従う。

**証明:** $\xi$ における下数であるような $\eta$ における上数 $Y$ が存在する。$\xi$ において、より大きい下数

```math
X > Y
```

を選ぶ。したがって $X$ は $\eta$ における上数である。定理 132 により、$\zeta$ において上数 $Z$ と下数 $U$ で

```math
Z - U = X - Y.
```

を満たすものを選ぶ。すると

```math
Y + Z = Y + ((X - Y) + U) = (Y + (X - Y)) + U = X + U,
```

であり、したがってこれは $\xi + \zeta$ における下数であり、(定理 129 の II) により)$\eta + \zeta$ における上数である。ゆえに

```math
\xi + \zeta > \eta + \zeta.
```

である。

**定理 135:**

```math
\xi > \eta \text{ ないし } \xi = \eta \text{ ないし } \xi < \eta
```

から

```math
\xi + \zeta > \eta + \zeta \text{ ないし } \xi + \zeta = \eta + \zeta \text{ ないし } \xi + \zeta < \eta + \zeta.
```

が従う。

**証明:** 第一の部分は定理 134 であり、第二は明らかであり、第三は

```math
\eta + \zeta > \xi + \zeta,
```

```math
\xi + \zeta < \eta + \zeta.
```

により第一の帰結である。

**定理 136:**

```math
\xi + \zeta > \eta + \zeta \text{ ないし } \xi + \zeta = \eta + \zeta \text{ ないし } \xi + \zeta < \eta + \zeta
```

から

```math
\xi > \eta \text{ ないし } \xi = \eta \text{ ないし } \xi < \eta.
```

が従う。

**証明:** 定理 135 から従う。なぜなら、三つの場合はいずれの側においても互いに排斥し合い、かつすべての可能性を尽くすからである。

**定理 137:**

```math
\xi > \eta, \quad \zeta > v
```

から

```math
\xi + \zeta > \eta + v.
```

が従う。

**証明:** 定理 134 により

```math
\xi + \zeta > \eta + \zeta
```

であり、かつ

```math
\eta + \zeta = \zeta + \eta > v + \eta = \eta + v,
```

であるから、

```math
\xi + \zeta > \eta + v.
```

である。

**定理 138:**

```math
\xi \geqq \eta, \quad \zeta > v \text{ または } \xi > \eta, \quad \zeta \geqq v
```

から

```math
\xi + \zeta > \eta + v.
```

が従う。

**証明:** 仮定に等号が含まれる場合は定理 134 によって、そうでない場合は定理 137 によって片付く。

**定理 139:**

```math
\xi \geqq \eta, \quad \zeta \geqq v
```

から

```math
\xi + \zeta \geqq \eta + v.
```

が従う。

**証明:** 仮定に二つの等号が含まれる場合は明らかであり、そうでない場合は定理 138 によって片付く。

**定理 140:**

```math
\xi > \eta,
```

ならば、

```math
\eta + v = \xi
```

はちょうど一つの解 $v$ を持つ。

**前注:**

```math
\xi \leqq \eta
```

に対しては、定理 138 により解は存在しない。

**証明:** I) 解は高々一つである。なぜなら

```math
v_1 \neq v_2
```

に対しては、定理 135 により

```math
\eta + v_1 \neq \eta + v_2.
```

だからである。

II) まず、$X$ が $\xi$ における下数、$Y$ が $\eta$ における上数であるような形 $X - Y$(したがって $X > Y$)の有理数の集合が、切断をなすことを示す。

1) そのような $X - Y$ が存在することは、定理 134 の証明の冒頭からすでに知っている。

$\xi$ におけるどの上数 $X_1$ も、そのような $X - Y$ ではない。なぜなら、この形のどの数に対しても

```math
X - Y < (X - Y) + Y = X < X_1.
```

だからである。

2) 上記の形の $X - Y$ が与えられ、

```math
U < X - Y,
```

ならば、

```math
U + Y < (X - Y) + Y = X,
```

であるから、

```math
U + Y = X_2
```

は $\xi$ における下数であり、

```math
U = X_2 - Y
```

は我々の集合に属する。

3) 上記の形の $X - Y$ が与えられたとき、$\xi$ における下数

```math
X_3 > X.
```

を選ぶ。すると

```math
(X_3 - Y) + Y > (X - Y) + Y,
```

```math
X_3 - Y > X - Y,
```

であり、したがって $X_3 - Y$ は、与えられた $X - Y$ よりも大きい我々の集合の数である。

したがって我々の集合は切断である。それを $v$ と呼ぶ。

これについて我々は

```math
\eta + v = \xi
```

を証明しよう。そのためには、次の二つのことを示せば十分である。

A) $v + \eta$ における各下数は $\xi$ における下数である。

B) $\xi$ における各下数は $v + \eta$ における下数である。

A) について:$v + \eta$ における各下数は、$X$ が $\xi$ における下数、$Y$ が $\eta$ における上数、$Y_1$ が $\eta$ における下数であり、かつ

```math
X > Y
```

であるような形

```math
(X - Y) + Y_1,
```

を持つ。さて

```math
Y > Y_1,
```

```math
((X - Y) + Y_1) + (Y - Y_1) = (X - Y) + (Y_1 + (Y - Y_1)) = (X - Y) + Y = X,
```

```math
(X - Y) + Y_1 < X,
```

であるから、$(X - Y) + Y_1$ は $\xi$ における下数である。

B) について:a) 与えられた $\xi$ における下数が同時に $\eta$ における上数であるとし、それをこのとき $Y$ と呼ぶ。

```math
X > Y
```

を満たす $\xi$ における下数 $X$ を選び、定理 132 により $\eta$ において下数 $Y_1$ と上数 $Y_2$ で

```math
Y_2 - Y_1 = X - Y.
```

を満たすものを選ぶ。すると

```math
Y > Y_1,
```

であるから、

```math
\begin{aligned}
Y_2 + (Y - Y_1) &= ((X - Y) + Y_1) + (Y - Y_1) = (X - Y) + (Y_1 + (Y - Y_1)) \\
&= (X - Y) + Y = X,
\end{aligned}
```

```math
Y - Y_1 = X - Y_2,
```

```math
Y = (Y - Y_1) + Y_1 = (X - Y_2) + Y_1;
```

であり、したがって $Y$ は $v + \eta$ における下数である。

b) 与えられた $\xi$ における下数が $\eta$ における下数であるならば、それは a) において $v + \eta$ における下数であることが示されたどの有理数よりも小さく、したがってそれ自身 $v + \eta$ における下数である。

**定義 35:** 定理 140 の $v$ を $\xi - \eta$ と呼ぶ($-$ 読み方:マイナス)。$\xi - \eta$ はまた差 $\xi$ マイナス $\eta$、あるいは $\xi$ から $\eta$ の減法によって生じる切断とも呼ばれる。

## § 4. 乗法

**定理 141:** I) $\xi$ と $\eta$ を切断とする。このとき、$X$ が $\xi$ における下数、$Y$ が $\eta$ における下数であるような形 $XY$ に書き表せる有理数の集合は、切断である。

II) この集合のいかなる数も、$\xi$ における上数と $\eta$ における上数の積として表すことはできない。

**証明:** 1) $\xi$ における任意の下数 $X$ と $\eta$ における任意の下数 $Y$ から出発すれば、$XY$ はこの集合に属する。

$\xi$ における任意の上数 $X_1$ と $\eta$ における任意の上数 $Y_1$ から出発すれば、$\xi$ ないし $\eta$ におけるすべての下数 $X$ ないし $Y$ に対して

```math
X < X_1, \quad Y < Y_1,
```

よって

```math
XY < X_1 Y_1,
```

```math
X_1 Y_1 \neq XY;
```

したがって $X_1 Y_1$ はこの集合に属さない。これで II) も同時に証明された。

2) $X$ を $\xi$ における下数、$Y$ を $\eta$ における下数とし、

```math
Z < XY
```

とする。このとき

```math
X \left(\frac{1}{X} \cdot Z\right) = \left(X \cdot \frac{1}{X}\right) Z = 1 \cdot Z = Z,
```

```math
\frac{1}{X} \cdot Z < \frac{1}{X} \cdot (XY) = \left(\frac{1}{X} \cdot X\right) Y = Y,
```

よって $\frac{Z}{X}$ は $\eta$ における下数である。したがって等式

```math
X \cdot \frac{Z}{X} = Z
```

は、$Z$ がわれわれの集合に属することを示す。

3) この集合の数が一つ与えられたとすると、それは $XY$ の形をもつ。ここで $X$ は $\xi$ における下数、$Y$ は $\eta$ における下数である。$\xi$ において下数

```math
X_1 > X
```

を選べば、

```math
X_1 Y > XY,
```

よってこの集合の数で $> XY$ であるものが存在する。

**定義 36:** 定理 141 で構成された切断を $\xi \cdot \eta$ と呼ぶ($\cdot$ は「掛ける」と読む。ただし普通この点は書かない)。これはまた $\xi$ と $\eta$ の積、あるいは $\xi$ に $\eta$ を乗じる乗法によって生じる切断とも呼ばれる。

**定理 142**(乗法の交換法則):

```math
\xi\eta = \eta\xi.
```

**証明:** どの $XY$ も $YX$ であり、逆もまた同様である。

**定理 143**(乗法の結合法則):

```math
(\xi\eta)\zeta = \xi(\eta\zeta).
```

**証明:** どの $(XY)Z$ も $X(YZ)$ であり、逆もまた同様である。

**定理 144**(分配法則):

```math
\xi(\eta + \zeta) = \xi\eta + \xi\zeta.
```

**証明:** I) $\xi(\eta + \zeta)$ におけるどの下数も

```math
X(Y + Z) = XY + XZ
```

である。ここで $X, Y, Z$ はそれぞれ $\xi, \eta, \zeta$ における下数である。数 $XY + XZ$ は $\xi\eta + \xi\zeta$ における下数である。

II) $\xi\eta + \xi\zeta$ におけるどの下数も

```math
XY + X_1 Z
```

の形をもつ。ここで $X, Y, X_1, Z$ はそれぞれ $\xi, \eta, \xi, \zeta$ における下数である。$X \geqq X_1$ の場合には数 $X$ を、$X < X_1$ の場合には数 $X_1$ を $X_2$ と記す。このとき $X_2$ は $\xi$ における下数であり、したがって $X_2(Y + Z)$ は $\xi(\eta + \zeta)$ における下数である。

```math
XY \leqq X_2 Y,
```

```math
X_1 Z \leqq X_2 Z
```

から

```math
XY + X_1 Z \leqq X_2 Y + X_2 Z = X_2(Y + Z);
```

が従う。よって $XY + X_1 Z$ は $\xi(\eta + \zeta)$ における下数である。

**定理 145:**

```math
\xi > \eta \text{ ないし } \xi = \eta \text{ ないし } \xi < \eta
```

から

```math
\xi\zeta > \eta\zeta \text{ ないし } \xi\zeta = \eta\zeta \text{ ないし } \xi\zeta < \eta\zeta.
```

が従う。

**証明:** 1)

```math
\xi > \eta
```

から、定理 140 により、適当な $v$ に対して

```math
\xi = \eta + v
```

が従い、よって

```math
\xi\zeta = (\eta + v)\zeta = \eta\zeta + v\zeta > \eta\zeta.
```

2)

```math
\xi = \eta
```

からは当然

```math
\xi\zeta = \eta\zeta
```

が従う。

3)

```math
\xi < \eta
```

から

```math
\eta > \xi
```

が従い、よって 1) により

```math
\eta\zeta > \xi\zeta,
```

```math
\xi\zeta < \eta\zeta.
```

**定理 146:**

```math
\xi\zeta > \eta\zeta \text{ ないし } \xi\zeta = \eta\zeta \text{ ないし } \xi\zeta < \eta\zeta
```

から

```math
\xi > \eta \text{ ないし } \xi = \eta \text{ ないし } \xi < \eta.
```

が従う。

**証明:** 定理 145 から従う。なぜなら、三つの場合はいずれの側においても互いに排反であり、かつすべての可能性を尽くすからである。

**定理 147:**

```math
\xi > \eta, \quad \zeta > v
```

から

```math
\xi\zeta > \eta v.
```

が従う。

**証明:** 定理 145 により

```math
\xi\zeta > \eta\zeta
```

であり、かつ

```math
\eta\zeta = \zeta\eta > v\eta = \eta v,
```

よって

```math
\xi\zeta > \eta v.
```

**定理 148:**

```math
\xi \geqq \eta, \quad \zeta > v \text{ または } \xi > \eta, \quad \zeta \geqq v
```

から

```math
\xi\zeta > \eta v.
```

が従う。

**証明:** 仮定に等号がある場合は定理 145 により、そうでない場合は定理 147 により片付く。

**定理 149:**

```math
\xi \geqq \eta, \quad \zeta \geqq v
```

から

```math
\xi\zeta \geqq \eta v.
```

が従う。

**証明:** 仮定に二つの等号がある場合は明らかである。そうでない場合は定理 148 により片付く。

**定理 150:** どの有理数 $R$ に対しても、$< R$ である有理数の集合は切断をなす。

**証明:** 1) 定理 90 により $X < R$ なる $X$ が存在する。$R$ 自身は $< R$ ではない。

2)

```math
X < R, \quad X_1 < X
```

ならば、

```math
X_1 < R.
```

である。

3)

```math
X < R
```

ならば、定理 91 により

```math
X < X_1 < R.
```

なる $X_1$ が存在する。

**定義 37:** 定理 150 で構成された切断を $R^*$ と呼ぶ。

(したがって、星印を付けた大きなラテン文字は切断を表すのであって、有理数を表すのではない。)

**定理 151:** $\xi \cdot 1^* = \xi$。

**証明:** $\xi \cdot 1^*$ は、$X$ が $\xi$ における下数であり、かつ

```math
Y < 1
```

であるようなすべての $XY$ の集合である。

そのような $XY$ はどれも $< X$ であり、よって $\xi$ における下数である。

逆に、$\xi$ における下数 $X$ が与えられたとする。このとき $\xi$ において下数

```math
X_1 > X
```

を選び、

```math
Y = \frac{X}{X_1}
```

とおく。このとき

```math
Y < \frac{X_1}{X_1} = 1,
```

よって

```math
X = X_1 Y
```

は $\xi \cdot 1^*$ における下数である。

**定理 152:** $\xi$ が与えられたとき、方程式

```math
\xi v = 1^*
```

は解 $v$ をもつ。

**証明:** $X$ が $\xi$ における任意の上数(ただし最小のものが存在する場合には、それを除くこともある)であるようなすべての数 $\frac{1}{X}$ の集合を考える。この集合が切断であることを示す。

1) この集合の数が存在する。なぜなら、$X$ が $\xi$ における上数であれば、$X + X$ もまた上数であり、しかも最小のものではないから、

```math
\frac{1}{X + X}
```

はこの集合に属する。

この集合に属さない有理数が存在する。なぜなら、$X_1$ を $\xi$ における任意の下数とすれば、$\xi$ におけるすべての上数 $X$ に対して

```math
X \neq X_1,
```

よって、

```math
X \cdot \frac{1}{X} = 1 = X_1 \cdot \frac{1}{X_1},
```

のゆえに

```math
\frac{1}{X} \neq \frac{1}{X_1};
```

したがって $\frac{1}{X_1}$ はわれわれの集合に属さない。

2) われわれの集合の数 $\frac{1}{X}$ が与えられ(したがって $X$ は $\xi$ における上数)、かつ

```math
U < \frac{1}{X}
```

であるとする。このとき

```math
UX < \left(\frac{1}{X}\right) X = 1 = U \cdot \frac{1}{U},
```

よって

```math
X < \frac{1}{U},
```

よって $\frac{1}{U}$ は $\xi$ における上数であり、最小のものではない。

```math
U = \frac{1}{1/U}
```

のゆえに、$U$ はわれわれの集合に属する。

3) われわれの集合の数 $\frac{1}{X}$ が与えられたとする(したがって $X$ は $\xi$ における上数であり、最小のものではない)。このとき $\xi$ において上数

```math
X_1 < X
```

を選び、次に定理 91 により

```math
X_1 < X_2 < X.
```

なる $X_2$ を選ぶ。このとき $X_2$ は $\xi$ における上数であり、最小のものではない。

```math
\left(\frac{1}{X}\right) X_2 < \left(\frac{1}{X}\right) X = 1 = \left(\frac{1}{X_2}\right) X_2
```

から

```math
\frac{1}{X} < \frac{1}{X_2},
```

が従い、こうして、与えられた数より大きい、われわれの集合の数が見出された。

したがって、われわれの集合は切断である。これを $v$ と呼ぶ。

これについて

```math
\xi v = 1^*
```

を証明する。そのためには、次の二つのことを示せば十分である。

A) $\xi v$ におけるどの下数も $< 1$ である。

B) $< 1$ であるどの有理数も $\xi v$ における下数である。

A) について。$\xi v$ におけるどの下数も

```math
X \cdot \frac{1}{X_1},
```

の形をもつ。ここで $X$ は $\xi$ における下数、$X_1$ は $\xi$ における上数である。

```math
X < X_1
```

から

```math
X \cdot \frac{1}{X_1} < X_1 \cdot \frac{1}{X_1} = 1.
```

が従う。

B) について。

```math
U < 1
```

とする。$\xi$ における任意の下数 $X$ を選び、次に定理 132 により、$\xi$ における下数 $X_1$ と $\xi$ における上数 $X_2$ で

```math
X_2 - X_1 = (1 - U) X.
```

を満たすものを選ぶ。このとき

```math
X_2 - X_1 < (1 - U) X_2,
```

```math
(X_2 - X_1) + UX_2 < (1 - U)X_2 + UX_2 = X_2 = (X_2 - X_1) + X_1,
```

```math
UX_2 < X_1,
```

```math
X_2 = \left(\frac{1}{U} \cdot U\right) X_2 = \frac{1}{U} (UX_2) < \frac{1}{U} \cdot X_1 = \frac{X_1}{U}.
```

したがって $\frac{X_1}{U}$ は $\xi$ における上数であり、最小のものではない。

から

```math
U = X_1 \cdot \frac{1}{X_1/U};
```

が従う。ここで $X_1$ は $\xi$ における下数、$\frac{1}{X_1/U}$ は $v$ における下数である。よって $U$ は $\xi v$ における下数である。

**定理 153:** $\xi, \eta$ が与えられているとき、方程式

```math
\eta v = \xi,
```

はちょうど一つの解 $v$ をもつ。

**証明:** I) 解は高々一つである。なぜなら、

```math
v_1 \neq v_2
```

に対しては、定理 145 により

```math
\eta v_1 \neq \eta v_2.
```

だからである。

II) $\tau$ を、定理 152 によってその存在が示された、

```math
\eta\tau = 1^*,
```

の解とすれば、

```math
v = \tau\xi
```

はわれわれの方程式を満たす。なぜなら、定理 151 により

```math
\eta v = \eta(\tau\xi) = (\eta\tau)\xi = 1^*\xi = \xi.
```

だからである。

**定義 38:** 定理 153 の $v$ を $\frac{\xi}{\eta}$ と呼ぶ($\xi$ 割る $\eta$ と読む)。$\frac{\xi}{\eta}$ はまた $\xi$ の $\eta$ による商、あるいは $\xi$ を $\eta$ で割る除法によって生じる切断とも呼ばれる。

## § 5. 有理切断と整切断

**定義 39:** $X^*$ の形の切断を有理切断と呼ぶ。

**定義 40:** $x^*$ の形の切断を整切断と呼ぶ。

(したがって、星印を付けた小さいラテン文字は切断を意味するのであって、整数を意味するのではない。)

**定理 154:**

```math
X > Y \text{ ないし } X = Y \text{ ないし } X < Y
```

から

```math
X^* > Y^* \text{ ないし } X^* = Y^* \text{ ないし } X^* < Y^*
```

が従い、また逆も成り立つ。

**証明:** I) 1)

```math
X > Y
```

から、$Y$ が $X^*$ における下数であることが従う。$Y$ は $Y^*$ における上数である。ゆえに

```math
X^* > Y^*.
```

2)

```math
X = Y
```

から当然

```math
X^* = Y^*
```

が従う。

3)

```math
X < Y
```

から

```math
Y > X,
```

が従い、ゆえに 1) により

```math
Y^* > X^*,
```

```math
X^* < Y^*.
```

II) 逆は明らかである。なぜなら、三つの場合はいずれの側においても互いに排斥し合い、かつすべての可能性を尽くすからである。

**定理 155:**

```math
\begin{gathered}
(X + Y)^* = X^* + Y^*; \\
(X - Y)^* = X^* - Y^* \quad \text{falls } X > Y; \\
(XY)^* = X^* Y^*; \\
\left(\frac{X}{Y}\right)^{\!*} = \frac{X^*}{Y^*}.
\end{gathered}
```

**証明:** I) a) $X^* + Y^*$ におけるどの下数も、$< X$ なる有理数と $< Y$ なる有理数との和である。ゆえにそれは $< X + Y$ であり、したがって $(X + Y)^*$ における下数である。

b) $(X + Y)^*$ におけるどの下数 $U$ も $< X + Y$ である。

```math
\frac{U}{X + Y} < 1,
```

```math
U = X \cdot \frac{U}{X + Y} + Y \cdot \frac{U}{X + Y}
```

から、$U$ が $< X$ なる有理数と $< Y$ なる有理数との和であり、したがって $X^* + Y^*$ における下数であることが従う。

ゆえに

```math
(X + Y)^* = X^* + Y^*.
```

である。

II)

```math
X > Y
```

から

```math
X = (X - Y) + Y,
```

が従い、ゆえに I) により

```math
X^* = (X - Y)^* + Y^*,
```

```math
(X - Y)^* = X^* - Y^*.
```

III) a) $X^* Y^*$ におけるどの下数も、$< X$ なる有理数と $< Y$ なる有理数との積である。ゆえにそれは $< XY$ であり、したがって $(XY)^*$ における下数である。

b) $(XY)^*$ におけるどの下数 $U$ も $< XY$ である。定理 91 により、

```math
U < U_1 < XY
```

なる有理数 $U_1$ を選ぶ。すると

```math
\frac{U_1}{X} < Y
```

であり、かつ

```math
\left(\frac{U}{U_1}\right) X < X.
```

である。

```math
U = \left(\left(\frac{U}{U_1}\right) X\right) \left(\frac{U_1}{X}\right)
```

によって、$U$ は $X^*$ における一つの下数と $Y^*$ における一つの下数との積として表されている。ゆえに $U$ は $X^* Y^*$ における下数である。

ゆえに

```math
(XY)^* = X^* Y^*.
```

である。

IV)

```math
X = \left(\frac{X}{Y}\right) \cdot Y,
```

であり、ゆえに III) により

```math
X^* = \left(\frac{X}{Y}\right)^{\!*} Y^*,
```

```math
\left(\frac{X}{Y}\right)^{\!*} = \frac{X^*}{Y^*}.
```

**定理 156:** $1$ の代わりに $1^*$ を取り、

```math
(x^*)' = (x')^*
```

と置くならば、整切断は自然数の五つの公理を満たす。

**証明:** $Q^*$ を整切断の集合とする。

1) $1^*$ は $Q^*$ に属する。

2) $x^*$ に対して、$(x^*)'$ が $Q^*$ の中に存在する。

3) つねに

```math
x' \neq 1,
```

であり、ゆえに

```math
(x')^* \neq 1^*,
```

```math
(x^*)' \neq 1^*.
```

4)

```math
(x^*)' = (y^*)'
```

から

```math
(x')^* = (y')^*,
```

```math
x' = y',
```

```math
x = y,
```

```math
x^* = y^*.
```

が従う。

5) 整切断からなる集合 $\mathfrak{M}^*$ が次の性質をもつとする:

I) $1^*$ は $\mathfrak{M}^*$ に属する。

II) $x^*$ が $\mathfrak{M}^*$ に属するならば、$(x^*)'$ も $\mathfrak{M}^*$ に属する。

このとき、$x^*$ が $\mathfrak{M}^*$ に属するような $x$ の集合を $\mathfrak{M}$ と記す。すると $1$ は $\mathfrak{M}$ に属し、$\mathfrak{M}$ の各 $x$ とともに $x'$ も $\mathfrak{M}$ に属する。ゆえにどの整数も $\mathfrak{M}$ に属し、したがってどの整切断も $\mathfrak{M}^*$ に属する。

$=$、$>$、$<$、和、差(存在する限りにおいて)、積および商は、有理切断においては定理 154 と定理 155 により古い概念に対応するから、有理切断は、我々が第2章で有理数について証明したすべての性質をもち、特に整切断は、整数について証明されたすべての性質をもつ。

ゆえに我々は有理数を投げ捨て、それを対応する有理切断で置き換え、以後、これまでのことに関してはもはや切断についてのみ語ることにする。(ただし有理数は、切断の概念における集合の中には残る。)

**定義 41:**(自由になった記号)$X$ は有理切断 $X^*$ を表し、有理数という言葉もこの有理切断に移る。同様に、整数という言葉も整切断に移る。

したがって我々は今後、例えば

```math
1^* + 1^* = 2^*
```

の代わりに単に

```math
1 + 1 = 2.
```

と書く。

**定理 157:** 有理数とは、最小の上数 $X$ が存在するような切断のことである。しかもそのとき、$X$ がその切断である。

**証明:** 1) 切断 $X$(古い $X^*$)においては、$X$(古い意味での有理数)が最小の上数である。

2) ある切断 $\xi$ において最小の上数 $X$ が存在するならば、どの下数も $< X$、どの上数も $\geqq X$ であり、ゆえにその切断は $X$(古い $X^*$)である。

**定理 158:** $\xi$ を切断とする。このとき、$X$ が下数であるのは

```math
X < \xi,
```

のとき、またそのときに限り、したがって上数であるのは

```math
X \geqq \xi.
```

のとき、またそのときに限る。

**証明:** 1) $X$ が $\xi$ における下数であるならば、$X$ は $X$(古い $X^*$)における上数であるから、

```math
X < \xi.
```

である。

2) $X$ が $\xi$ における上数であって、しかも最小のものであるならば、定理 157 により

```math
X = \xi.
```

である。

3) $X$ が $\xi$ における上数であって、最小のものでないならば、より小さい上数 $X_1$ を選べ。すると $X_1$ は $X$ における下数であり、ゆえに

```math
X > \xi.
```

である。

**定理 159:**

```math
\xi < \eta,
```

ならば、

```math
\xi < Z < \eta.
```

なる $Z$ が存在する。

**証明:** $\xi$ における上数であって $\eta$ における下数であるような $X$ を選び、次に $\eta$ におけるより大きい下数 $Z$ を選べ。すると定理 158 により

```math
\xi \leqq X < Z < \eta.
```

である。

**定理 160:** どの

```math
Z > \xi\eta
```

も、

```math
Z = XY, \quad X > \xi, \quad Y > \eta.
```

の形にすることができる。

**証明:** $\zeta$ は、二つの切断 $1$ と

```math
\frac{Z - \xi\eta}{(\xi + \eta) + 1}.
```

のうち最小のものを表すとする。すると

```math
\zeta \leqq 1, \quad \zeta \leqq \frac{Z - \xi\eta}{(\xi + \eta) + 1}.
```

である。定理 159 により、

```math
\xi < Z_1 < \xi + \zeta, \quad \eta < Z_2 < \eta + \zeta.
```

なる $Z_1$ と $Z_2$ を選べ。すると

```math
\begin{aligned}
Z_1 Z_2 &< (\xi + \zeta)(\eta + \zeta) = (\xi + \zeta)\eta + (\xi + \zeta)\zeta \leqq (\xi + \zeta)\eta + (\xi + 1)\zeta \\
&= (\xi\eta + \zeta\eta) + (\xi + 1)\zeta = \xi\eta + ((\xi + \eta) + 1)\zeta \leqq \xi\eta + (Z - \xi\eta) = Z.
\end{aligned}
```

である。

```math
Z = \frac{Z}{Z_2} \cdot Z_2
```

において

```math
X = \frac{Z}{Z_2} = Z \cdot \frac{1}{Z_2} > (Z_1 Z_2) \cdot \frac{1}{Z_2} = Z_1 > \xi, \quad Y = Z_2 > \eta;
```

であり、ゆえに $Z$ は望まれた仕方で分解されている。

**定理 161:** どの $\zeta$ に対しても、

```math
\xi\xi = \zeta
```

はちょうど一つの解をもつ。

**証明:** I) 解は高々一つである。なぜなら

```math
\xi_1 > \xi_2
```

から

```math
\xi_1 \xi_1 > \xi_2 \xi_2.
```

が従うからである。

II) 我々は

```math
XX < \zeta.
```

なる有理数 $X$ の集合を考える。これは一つの切断をなす。なぜなら:

1)

```math
X < 1 \text{ かつ } X < \zeta,
```

ならば

```math
XX < X \cdot 1 = X < \zeta.
```

である。

```math
X \geqq 1 \text{ かつ } X \geqq \zeta,
```

ならば

```math
XX \geqq X \cdot 1 = X \geqq \zeta.
```

である。

2)

```math
XX < \zeta, \quad Y < X
```

から

```math
YY < XX < \zeta.
```

が従う。

3)

```math
XX < \zeta.
```

とする。$Z$ を、二つの切断 $1$ と

```math
\frac{\zeta - XX}{X + (X + 1)}.
```

のうち最小のものより小さく選べ。すると

```math
Z < 1, \quad Z \leqq \frac{\zeta - XX}{X + (X + 1)};
```

であり、そのとき

```math
X + Z > X
```

であって、かつ

```math
\begin{aligned}
(X + Z)(X + Z) &= (X + Z)X + (X + Z)Z < (XX + ZX) + (X + 1)Z \\
&= XX + (X + (X + 1))Z \leqq XX + (\zeta - XX) = \zeta.
\end{aligned}
```

である。

```math
\xi\xi = \zeta.
```
