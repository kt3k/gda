# 序文

## 学習者のための序文

**1.** 後にある専門家のための序文は、どうか読まないでほしい!

**2.** 前提として要求するのは、論理的な思考とドイツ語の知識だけだ。学校数学の知識も、ましてや高等数学の知識も、いっさい前提としない。

先回りして反論に答えておこう。「一つの数」「数がない」「二つの場合」「与えられた全体に属するすべてのもの」などは、ドイツ語の明確な言葉の組み立てである。定理 1、定理 2、…、定理 301(公理、定義、章、節についても同様)や、場合分けにおける 1)、2) などは、定理、公理、…、場合を区別するための標識であって、参照するときに、たとえば「定理・薄青」「定理・濃青」などと呼ぶよりも便利だからそうしているにすぎない。「301」までなら、いわゆる正の整数の導入にはそもそも何の困難もない。最初の困難——それは第1章で克服される——は、正の整数の全体

```math
1, \ldots
```

にある。コンマの後ろの神秘的な点の列を伴うこの全体(第1章では自然数と呼ばれる)、それらに対して行う演算の定義、そしてそれに付随する定理の証明にこそ困難があるのだ。

私は対応する事柄をすべて順を追って展開していく。第1章では自然数について、第2章では正の分数と正の有理数について、第3章では正の(有理および無理)数について、第4章では実数(正、負、および零)について、第5章では複素数について。つまり、君が学校ですでに扱ったことのある数についてだけ話すのである。

その意味で:

**3.** 学校で習ったことは、どうかすべて忘れてほしい。なぜなら君はそれを学んではいないのだから。

しかし何につけても、学校で習った対応する箇所を思い出してほしい。なぜなら君はそれを忘れてもいないのだから。

**4.** 九九は、すでに定理

```math
2 \cdot 2 = 4,
```

からして、本書には現れない。しかし第1章 § 4 の練習問題として、

```math
\begin{aligned}
2 &= 1 + 1,\\
4 &= ((1 + 1) + 1) + 1
\end{aligned}
```

を定義して、この定理を証明することを君に勧める。

**5.** 君を「君」と呼ぶ無礼を許してほしい。こうするのは、読者に「読め」「見よ」と呼びかけるのが習わしだからというだけではない。この本が部分的には usum delphinarum(王子教育)のために書かれたものだからでもある。というのも、周知のとおり(E. Landau, Vorlesungen über Zahlentheorie, Bd. 1, S. V を見よ)、私の娘たちはすでに何学期も(化学を)学んでおり、学校ですでに微分積分学を習ったと思い込んでいるのに、今日に至るまでなぜ

```math
x \cdot y = y \cdot x
```

であるのかを知らないのだ。

ベルリン、1929年12月28日。

エトムント・ランダウ。

## 専門家のための序文

この小冊子は、以下の問いにおいて私の立場を共有**しない**(残念ながら多数派を占める)同僚たちへの、一つの譲歩である。

学校では、初等数学を厳密で隙のない体系として構築することは当然断念せざるを得ないが、大学の数学教育は、聴講者に素材と結果だけでなく、証明の方法にも習熟させるべきである。数学を主として物理学その他の科学への応用のために学ぶ者、すなわち多くの場合さらなる数学的補助定理を自分で組み立てなければならない者であっても、踏み慣らされた道を安全に進み続けられるのは、歩くことを学んだとき、つまり偽と真、予想と証明(あるいは、ある人々の美しい言い方によれば、非厳密な証明と厳密な証明)とを区別できるようになったときだけである。

だから私は——幾人かの私の師と同僚、私がその著作から学んだ幾人かの著者、そして私の学生の大多数にならって——学生が最初の学期のうちに、解析学がどのような、公理として仮定された基本事実の上に隙なく構築されるのか、そしてこの構築がどのように始められうるのかを学ぶことが正しいと考える。公理の選び方については、周知のとおり様々な流儀がありうる。だから、実数について通常の計算法則の多くと本書の定理 205(デデキントの主定理)を公理として要請するやり方を、私は誤りだと言うのではなく、私の個人的立場とはほとんど正反対だと言うのである。もちろん私は五つのペアノの公理の無矛盾性を証明しはしない(なぜなら、それはできないことだからである)。しかしそのおのおのが先行する公理から独立であることは明白である。他方、公理の数をそのように増やすと、学習者にはただちに、そのうちの少なからぬものが先行する事柄から証明(利口な者なら付け加えるだろう——あるいは反駁)できるのではないか、という疑問が浮かぶ。そしてこれらすべての事柄が証明可能であることは何十年も前から知られているのだから、学習者がその(一貫してごく易しい)証明を勉学の初めに学べるようにしてやることは、実に望ましいことである。

デデキントの主定理(あるいは、実数を基本列によって基礎づける場合のそれと同等の代用物)すら基礎に置かれないことが多い、という点についてここで詳しく論じるつもりはない。その場合、微分学の平均値の定理、それに基づく「ある区間で導関数が消える関数はそこで定数である」という定理、あるいはたとえば「単調に減少する有界な数列はある極限値に収束する」という定理などが、何の証明もなしに現れるか、さらに悪いことには、証明になっていない証明もどきとともに現れることになる。もう一方の立場のこの極端な変種を代表する人々の数は、単調に減少しているように私には思われるばかりでない。上に述べた定理によればこの数がある極限値に収束するはずだが、その極限値はおそらく零ですらあろう。

しかし、自然数の基礎づけから始めるということは、めったに行われない。私自身も告白すれば、デデキントに従って実数論を扱うことは昔から欠かさなかったが、かつては整数と有理数の性質を前提としていた。もっとも直近の三回は、整数から始めるほうを選んだ。ただし一度、そして来たる夏学期についても、すぐに微分をしたい、あるいは数概念の解説全体を最初の学期には(あるいはことによると全く)学びたくないという聴講者への譲歩として、私は講義を同時進行の二つに分け、その一方を「解析学の基礎(Grundlagen der Analysis)」と名づけた。この講義で私は、自然数についてのペアノの公理から出発して、実数論と複素数論にまで到達する。もっとも聴講者は最初の学期にはまだ複素数を必要としない。しかしその導入はごく簡単であり、労せずすぐに付け加えられるのである。

さて、全文献を見渡しても、上の意味での数の計算を基礎づけることだけを慎ましい目標に掲げた教科書は存在しない。また、序章でこれを試みている浩瀚な著作にしても、その際(意識的にか無意識的にか)実に多くのことを読者に委ねている。

この小著は——もしそれがふさわしいと認められるならば——もう一方の教育方針の同僚、すなわち基礎を扱わない同僚のすべてに、少なくとも、欠けているもの、そして欠けているものだけが切れ目のない連関のもとに叙述されている典拠を指示する可能性を与えようとするものである。学校ですでに結果を知っていれば——実際そうなのだが——そして抽象的な最初の四、五ページを乗り越えさえすれば、読むのはごく容易である。

私がこの小著を公にするのをためらうのは、これによって私が、(カルマール氏の口頭による伝達を除けば)何も新しいことを言えない領域について公刊することになるからである。しかし、私のこの、部分的には退屈な労苦を、他の誰も引き受けてはくれなかったのだ。

しかし、この「公衆への逃避」への決定的なきっかけを与えたのは、ある具体的な出来事であった。

もう一方の方針の人々は常々、学生は勉学の後の課程で、講義なり文献なりを手がかりにこの事柄をいずれ学ぶだろう、と考えている。そして、私の尊敬する友人たちや論敵たちの誰一人として、たとえば私の講義の中に必要なことがすべて見いだされることを疑いはしなかったであろう。私自身もそう信じていた。ところが、次のような恐ろしい事件が私の身に起こったのである。当時の私の助手であり親愛なる同僚である私講師グランジョ博士(現在はサンティアゴ大学教授)が、私の講義ノートをもとに解析学の基礎について講義をし、私の原稿を返却する際にこう述べたのだ。彼は、講義を進めるうちに、ペアノの公理に別の公理を付け加えることが必要だと判断した、なぜなら私が辿った通常の道筋にはある特定の欠落があるからだ、と。細部に立ち入る前に、先回りしてすぐに述べておこう。

1. グランジョの異議は正当であった。
2. 全体の冒頭で列挙することのできない公理(後から出てくる概念に結びついているため)は、はなはだ遺憾なものである。
3. グランジョの公理は(デデキントからすでに学べたはずのことだが)すべて証明可能であり、(以下の本書全体を見よ)ペアノの公理だけで済むのである。

異議が当てはまる箇所は三つある。

**I.** 自然数に対する $x + y$ の定義において。

**II.** 自然数に対する $x \cdot y$ の定義において。

**III.** 何らかの数領域に対して $x + y$ と $x \cdot y$ がすでに得られた後の、$\sum_{n=1}^{m} x_n$ と $\prod_{n=1}^{m} x_n$ の定義において。

三つの場合とも事情は同様であるから、ここでは自然数 $x, y$ に対する $x + y$ についてだけ述べる。たとえば数論の講義で、自然数についての何らかの定理を、まず $1$ について正しいことを証明し、次に $x$ について正しいことから $x + 1$ について正しいことを証明する、という仕方で証明すると、時折聴講者から、命題を $x$ についてあらかじめ証明していないではないか、という異議が出るのが常である。この異議は不当だが、許されるものである。その学生は帰納法の公理について聞いたことがなかっただけなのだ。グランジョの異議も似たように聞こえるが、違いは、それが正当であったことである。だから私はそれを許さざるをえなかった。ペアノは自らの五つの公理に基づき、$x$ を固定してすべての $y$ に対する $x + y$ を次のように定義する。

```math
\begin{aligned}
x + 1 &= x',\\
x + y' &= (x + y)',
\end{aligned}
```

そして彼とその後継者たちは、これによって $x + y$ は一般に定義された、と考える。なぜなら、それが定義されている $y$ の集合は $1$ を含み、$y$ とともに $y'$ も含むからだ、と。

しかし、$x + y$ はそもそも定義されていないのである。

もし「$\leqq y$ なる数」という概念を持っていて(ペアノの道筋ではそうではない。順序は加法の後に初めて導入されるからである)、次の性質

```math
\begin{aligned}
f(1) &= x',\\
f(z') &= (f(z))' \quad \text{für } z < y.
\end{aligned}
```

を持つ、$z \leqq y$ に対して定義された $f(z)$ が存在するような $y$ の集合について語るのであれば、それで問題はないであろう。

デデキントの基礎づけはこのように進む。プリンストンの同僚フォン・ノイマンの親切な助力を得て、私は順序をあらかじめ導入した上で(これは読者にとって快適ではなかったであろうが)、この小冊子のためにそのような道筋を仕上げていた。しかし土壇場になって、セゲドのカルマール博士によるはるかに簡単な証明を知った。今ではこの事柄はきわめて簡単に見え、その証明は第1章の他の証明にあまりにもよく似ているので、私が上のように罪と償いの告白をこれほど詳細に記録に残さなかったならば、専門家でさえこの要点に気づかなかったであろう。$x \cdot y$ についても全く同様である。もっとも $\sum_{n=1}^{m} x_n$ と $\prod_{n=1}^{m} x_n$ はデデキントの道筋によってのみ可能である。しかし第1章 § 3 以降は $z \leqq y$ なる数の集合が得られているのである。

読者にできるだけ負担をかけないために、私はある種の(それほど分量の多くない)語句のまとまりを、複数の章あるいはすべての章で繰り返した。専門家に対してなら、たとえば定理 16 と 17 の証明の際に一度だけこう言えば十分であったろう。「この基礎づけは、記号 $<$ と $=$ が定義されていて所定の先行する性質を持つ、あらゆる数のクラスに対して成り立つ」と。このように繰り返された推論の仕方は、当該のすべての章に現れざるをえなかった定理に関わるものである。それらの定理が後続の部分で用いられたからである。しかし $\sum_{n=1}^{m} a_n$ と $\prod_{n=1}^{m} a_n$ は最後の章で導入しさえすれば、それによって下位の数種に対しても得られる。それゆえ私はこれを複素数まで持ち越すことにする。減法と除法についての諸定理も同様である。前者はたとえば自然数に対しては、当然のことながら、被減数がつねに減数より大きい場合にのみ成り立ち、後者はたとえば自然数の場合、すべての除法が割り切れる場合にのみ成り立つ。

私の本は、傍論を断念して、容赦のない電報体(「公理」「定義」「定理」「証明」、時折「前注」のみ。この五つの欄のいずれにも属さない言葉はまれである)で書かれている。これほど易しい題材にはこの文体こそふさわしい。

数十年の準備の末に、私はこの小著を、普通の学生が二日で読めるように書き上げたと望んでいる。そしてその後は、(形式的な規則は学校ですでに知っているのだから)帰納法の公理とデデキントの主定理を除いて、内容の全部を忘れてしまってもかまわないのである。

さらにもし、もう一方の方針の同僚の誰かに、この事柄がその初学者向け講義で(以下の道筋であれ他のどんな道筋であれ)扱えるほど易しいものに見えるならば、私は、より大きな規模では望む勇気のない目標を達成したことになるであろう。

ベルリン、1929年12月28日。

エトムント・ランダウ。
